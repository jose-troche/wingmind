# Terrain masking

A ground radar can only see you along a straight line. The profile shows the terrain between the nearest SAM site and your aircraft.

- **Green dashed** sight line: a ridge blocks it. You are masked.
- **Red** sight line: clear line of sight. The site can track you if you are inside its ring.

GBAD cuts each SAM ring with line of sight on 64 radials, so ridges carve safe corridors. Descending behind a ridge breaks the track, but NAV must approve the terrain clearance first.
